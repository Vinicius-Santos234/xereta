**Status:** **aprovada** em 02/10, sem nenhuma etapa começada
**Data:** 2026-10-02
**Origem:** reel do app Coucou (instagram.com/reel/Dd-PScpoDju), assistido em 02/10.

## 1. Objetivo

Uma ilha pequena no topo da tela, com um mascote, que mostra ao vivo o que o Claude Code
está fazendo e deixa **aprovar ou negar um pedido de permissão ali mesmo**, sem voltar ao
terminal.

**Uma frase de sucesso:** peço ao Claude Code *"roda os testes e faz o push"*, vou para o
navegador e vejo a ilha passar por "Rodando npm test" até ficar amarela com `git push origin
main`. Clico em **Permitir** sem sair do navegador, e o mascote comemora quando termina.

**E a promessa que não pode quebrar:** o Xereta fechado, travado ou com defeito **nunca**
atrapalha o Claude Code. Sem resposta da ilha, tudo volta a ser como é hoje, com o pedido no
terminal.

## 2. Fora de escopo do MVP

| Fora | Por quê |
|---|---|
| Integrações (Stripe, GitHub, n8n, Vercel) | Estão no Coucou, mas para nós são candidatas a diferencial, não base. Ver `ideias/diferenciais.md` |
| Chat sobre arquivo arrastado, seletor de modelos, chaves de API | É outro produto dentro do produto. Quando entrar, as chaves vão para o cofre do sistema, nunca para disco |
| Outras fontes: Codex, Gemini, Ollama, scripts próprios | **Fora do MVP, mas a arquitetura nasce pronta para elas** (D10). Cada uma vira só um adaptador novo |
| Atalhos globais de teclado (Y/N) | Atalho global sequestra o que você digita em outros apps, e no teclado ABNT2 o AltGr é Ctrl+Alt, então combinações com Ctrl+Alt colidem. Fica para a v2, com cuidado |
| Iniciar junto com o Windows | Abrir na mão basta para validar. Na v2 entra o plugin `autostart` do Tauri |
| Mac e Linux | O MVP é Windows. Onde não custa nada, o código evita o que é exclusivo do Windows |
| Vários monitores | Só o monitor principal |
| Esconder durante jogo ou vídeo em tela cheia | Fica para a v2 (está nos riscos) |
| "Sempre permitir isto" (gravar regra de permissão) | Fica para a v2. Antes é preciso confirmar o que o `PermissionRequest` aceita devolver |
| Instalador assinado, publicação, site | Só quando decidir abrir o projeto |
| Sons e easter eggs | Visual primeiro |
| Paridade com o Coucou | Correr atrás de cada recurso dele é uma corrida perdida e tira o foco do que é nosso. O MVP é o núcleo, e depois entram os diferenciais |

## 3. Decisões

| # | Decisão | Escolha | Motivo |
|---|---|---|---|
| D1 | Stack | **Tauri 2** + **JavaScript puro** na interface, sem TypeScript nem framework | Decidido em 02/10: leve para um app que fica aberto o dia todo, com sistema de permissões explícitas e bom para um possível open source. A interface é pequena demais para justificar React |
| D2 | Divisão Rust / JS | **Núcleo fino:** o Rust só recebe HTTP, repassa à página e devolve a decisão. Toda regra de negócio fica em JS | O Rust é escrito uma vez e quase não muda. Adicionar uma fonte nova é só JS. O Rust do projeto também é o seu primeiro Rust: pequeno e completo |
| D3 | Como o Claude Code avisa | Hooks do tipo **`http`**, direto para o app, sem script no meio | Nenhum processo extra a cada evento. Conexão recusada é erro não bloqueante: o Claude Code segue normal (confirmado nos docs em 02/10) |
| D4 | Endereço | Só **`127.0.0.1`**, porta fixa **47321** (configurável). Porta ocupada vira erro visível na ilha | Os hooks no `settings.json` apontam para uma porta fixa. Trocar de porta sozinho quebraria tudo em silêncio |
| D5 | Autenticação | Token aleatório gerado na instalação, enviado como `Authorization: Bearer` e gravado **literal** no `settings.json` | Qualquer programa da máquina consegue falar com `127.0.0.1`. Sem token, outro processo aprovaria um `git push` no seu lugar. O token é literal, e não variável de ambiente, porque variável nova não chega a um processo já aberto (lição de 02/10) |
| D6 | Sem decisão | Resposta vazia, e o Claude Code cai no fluxo normal do terminal. **Nunca permitir por timeout, nunca negar em silêncio** | O pior defeito possível deste app é aprovar algo que você não viu. O segundo pior é negar sem você saber |
| D7 | Espera na ilha | Pedido aberto por até **45 s** (configurável); o `timeout` do hook é de **60 s** | A folga garante que a ilha responda vazio antes de o Claude Code cortar. O valor é revisto depois da V1 |
| D8 | Eventos de status | Resposta imediata, com `timeout` do hook de **2 s** | Status não pode deixar o Claude Code mais lento. Se a ilha travar, o atraso máximo é de 2 s, e só nesse caso |
| D9 | Privacidade | Nada do conteúdo das ferramentas (`tool_input`) vai para disco. O log guarda só a hora, a fonte e o tipo do evento | `tool_input` pode trazer segredo: um `.env` sendo editado, um comando com token |
| D10 | Contrato entre fontes e ilha | **Formato comum de evento** (§4). Cada fonte tem um adaptador em JS que traduz para ele | É o que deixa Codex, Gemini e Ollama virarem só um arquivo novo |
| D11 | Não atrapalhar cliques | A **janela muda de tamanho** (pílula ↔ ilha expandida) em vez de usar clique transparente | Como a janela nunca é maior que o que se vê, ela nunca rouba um clique fora da ilha. No Tauri, ignorar o cursor vale para a janela inteira, sem meio-termo |
| D12 | Identidade visual | **Visual e mascote próprios.** O Xereta **espia por cima da borda** da tela. Nada de quadradinho branco de olhos grandes (é o Mochi), e o termo "Dynamic Island" não aparece em lugar nenhum (é da Apple) | Mecânica igual não é problema; cara igual é. O que torna o app nosso é o personagem |
| D16 | Feito no Brasil | **PT-BR desde a primeira linha**, com todos os textos num arquivo só (`textos/pt-BR.js`), pronto para o inglês depois. O mascote fala como brasileiro ("Opa!", "Bora?", "Deu ruim") | "Feito no Brasil" só pesa se aparecer no produto. Tradução de app gringo já existe (PR #80 do Coucou). O que não existe é um app que **nasce** brasileiro |
| D13 | Foco | Expandir a ilha **não rouba o foco** do app em que você está | Senão ela atrapalha justamente quem está digitando em outro lugar |
| D14 | Instalar os hooks | `npm run hooks -- instalar` / `remover`: **mostra o diff antes**, só grava depois de confirmar, faz backup com data, **recusa gravar se o arquivo mudou desde a prévia** e pode rodar várias vezes | O `settings.json` já tem 4 hooks do vault (SessionStart, PreToolUse, PostToolUse, Stop) que **não podem ser tocados**. A prévia com a recusa foi ideia aprendida no Coucou |
| D15 | Repositório | Git local desde a E0. GitHub e licença são decisão sua, antes de qualquer publicação | Abrir o projeto é uma possibilidade, não um plano com data |

## 4. Arquitetura

```
Claude Code ──POST /fontes/claude-code──▶ ┌──────── Rust (núcleo fino) ────────┐
  (hooks http, Bearer token)              │ valida token e tamanho              │
                                          │ status → 200 vazio na hora          │
                                          │ permissão → guarda o pedido aberto  │──evento──▶ JS
                                          │ decisão chega → responde o JSON     │◀─comando── JS
                                          └─────────────────────────────────────┘
JS (interface): adaptadores/claude-code.js → formato comum → estado da ilha → mascote
```

**Formato comum de evento** (o contrato da D10):

```js
{
  fonte: 'claude-code',          // amanhã: 'codex', 'gemini', 'ollama', 'script'
  sessao: '<session_id>',
  projeto: 'korus',              // nome da pasta do cwd
  tipo: 'inicio' | 'pensando' | 'ferramenta' | 'permissao' | 'erro' | 'fim' | 'saida',
  resumo: 'Rodando npm test',    // o que a ilha escreve
  pedidoId: '…'                  // só em 'permissao': liga o clique ao pedido certo
}
```

**Do Claude Code para o formato comum** (hooks instalados na E3):

| Hook | Tipo | O que a ilha mostra |
|---|---|---|
| `SessionStart` | `inicio` | Sessão aparece com o nome do projeto |
| `UserPromptSubmit` | `pensando` | Mascote pensando |
| `PreToolUse` | `ferramenta` | "Lendo billing.ts", "Editando billing.ts", "Rodando npm test" |
| `PostToolUseFailure` | `erro` | Careta rápida, sem travar |
| `PermissionRequest` | `permissao` | Ilha amarela e expandida, com Permitir, Negar e No terminal |
| `Stop` | `fim` | Mascote feliz |
| `StopFailure` | `erro` | Mascote triste, com o motivo |
| `SessionEnd` | `saida` | Sessão some |

A resposta de permissão segue o formato dos docs:
`{"hookSpecificOutput":{"hookEventName":"PermissionRequest","decision":{"behavior":"allow"}}}`
(ou `"deny"`). "No terminal" e o timeout respondem com corpo vazio.

## 5. Etapas e critérios de aceite

### E0 — Ambiente e esqueleto
> **02/10 — ambiente instalado:** Build Tools do VS **2022** (17.14, carga de trabalho C++;
> a 2026 foi evitada por ser nova demais), Rust **1.99.0** (`stable-x86_64-pc-windows-msvc`,
> via `rustup` 1.29.1) e as extensões `rust-analyzer` e `tauri-vscode` no Antigravity. Um
> "olá mundo" compilou e rodou, o que prova que o linker do MSVC funciona.
>
> **02/10 — esqueleto:** `git init` (branch `main`) e projeto gerado com `create-tauri-app`
> 4.7.4, template `vanilla`, identificador `com.viniciussantos.xereta`. `npm run tauri dev`
> abriu a janela; a primeira compilação levou 4m55s (351 crates), sem erros nem avisos.
> **Falta:** a medição do instalador (`npm run tauri build`).

- Rust instalado pelo `rustup` e Build Tools do Visual Studio com "Desenvolvimento para
  desktop com C++" (o WebView2 já está instalado: v154). **As Build Tools são só o
  compilador e o linker da Microsoft, sem a IDE.** O editor continua sendo o Antigravity,
  com a extensão `rust-analyzer`.
- Projeto criado com `npm create tauri-app@latest` (template JS puro), dentro de `Desktop\Xereta`,
  com `git init`.
- `npm run tauri dev` abre uma janela.
- `npm run tauri build` gera um instalador com **menos de 15 MB**. O número medido fica anotado.

### E1 — A ilha e o mascote
- **Antes do código, o personagem.** Um protótipo em HTML (`design/mascote.html`) com os 6
  estados lado a lado, aprovado por você. Ele precisa ser reconhecível como **nosso** sem
  legenda, e não pode lembrar o Mochi.
- Janela sem borda, transparente, sempre no topo, sem ícone na barra de tarefas,
  centralizada no alto do monitor principal.
- **Recolhida:** pílula de ~140×34 px com o mascote espiando. **Expandida** ao passar o mouse:
  ~420×110 px, em menos de 200 ms, e recolhe 1 s depois de o mouse sair.
- Com o VS Code maximizado atrás, **todo clique fora da pílula chega ao VS Code** (D11).
- Expandir não tira o foco do app em que você está digitando (D13).
- O mascote tem 6 estados, alternáveis por um menu de teste: parado, pensando, trabalhando,
  esperando você, feliz e erro.
- Ícone na bandeja com **Sair**.
- Com a ilha parada, ela usa **menos de 100 MB de memória** (Gerenciador de Tarefas). O número fica anotado.

### E2 — A ponte em Rust
Tudo testado com `curl` antes de existir hook:
- `POST` sem token ou com token errado → `401` e nada aparece na ilha.
- Evento de status → `200` vazio em **menos de 50 ms**, e a ilha atualiza.
- Pedido de permissão → a conexão **fica aberta** até o clique. Permitir e Negar devolvem
  exatamente o JSON da §4.
- Sem clique em 45 s → `200` vazio. **Nenhum caminho de timeout ou erro devolve `allow`**,
  e há um teste para isso.
- Corpo acima de 10 MB → `413`.
- Porta ocupada → a ilha mostra o erro e o app **não** troca de porta.
- O Rust não contém a palavra "claude": ele não sabe de onde vêm os eventos (D2).

### E3 — Adaptador do Claude Code e instalador dos hooks
- `npm run hooks -- instalar` mescla os 8 hooks da §4 e guarda backup com data.
  - Os 4 hooks do vault continuam **idênticos** (comparação do JSON antes e depois).
  - Rodar duas vezes deixa o arquivo igual a rodar uma vez.
  - `remover` devolve um JSON **igual** ao de antes da instalação.
- Numa sessão real, a ilha mostra o nome do projeto, cada ferramenta com o resumo certo e o
  mascote feliz no `Stop`.
- **App fechado:** o Claude Code funciona normalmente. Medir 20 chamadas de ferramenta com o
  app fechado contra sem hooks instalados: diferença **menor que 50 ms por chamada**.

### E4 — Permissão pela ilha
- V1 e V2 (§6) respondidas e registradas aqui antes de fechar a etapa.
- **Permitir** → a ferramenta roda. **Negar** → não roda, e o Claude Code fica sabendo.
  **No terminal** → o pedido aparece no terminal como sempre.
- Fechar o app com um pedido aberto → o pedido aparece no terminal.
- Duas sessões pedindo ao mesmo tempo → a ilha mostra a primeira com "+1", e cada clique vai
  para o pedido certo (`pedidoId`). Teste com duas sessões reais.
- A ilha mostra a ferramenta e o alvo: o comando do Bash ou o arquivo do Edit/Write.

## 7. Riscos

| Risco | Plano |
|---|---|
| A ilha cobre o centro da barra de título de janelas maximizadas | A pílula é pequena e o centro da barra de título costuma ser só texto. Se incomodar, a posição vira configuração |
| Fica por cima de vídeo e jogo em tela cheia | É v2 (fora de escopo). Até lá, o ícone da bandeja tem **Pausar** além de Sair |
| Token vazado (o `settings.json` foi parar num backup ou print) | `npm run hooks -- instalar --novo-token` troca o token. O token só vale para `127.0.0.1` |
| Formato dos hooks do Claude Code mudar numa versão nova | Só o adaptador `claude-code.js` muda. A versão testada fica anotada (hoje: 2.1.287) |
| Defender acusar o instalador sem assinatura como vírus | **Já aconteceu com o Coucou** (issue #103, "Trojan:Win32/Wacatac"), e o download dele no Windows está suspenso. Para uso próprio, compilar do código basta. Antes de publicar, assinar o instalador; o caminho de assinatura é decisão da spec de publicação |
| Primeiro contato com Rust travar o ritmo | É o motivo da D2: Rust pequeno, numa etapa só (E2), testado com `curl` antes de ligar no resto |
